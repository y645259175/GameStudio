# Breakout · 打砖块 GDD

## 概述

经典 Breakout 复刻：玩家操控屏幕底部的挡板，反弹球体撞击上方砖块阵列，消灭所有砖块即通关。

- **核心体验**：精准操控 + 连续消砖的爽快感
- **目标玩家**：休闲玩家 / 全年龄
- **类型**：2D Arcade / Breakout Clone
- **引擎**：Godot 4.x · GDScript
- **平台**：PC（Windows）
- **分辨率**：1280×720
- **预期游玩时长**：单局 3-5 分钟，全 5 关 15-25 分钟

## 玩法循环

### Core Loop（每秒）

```
[发球] → [球弹射] → [挡板接球/反弹] → [球击中砖块] → [砖块消失/掉道具] → [得分]
          ↓ 漏接
      [失去生命] → [剩余生命 > 0 ? 重新发球 : Game Over]
```

### Meta Loop（每关）

```
[开始关卡] → [消灭所有砖块] → [通关] → [下一关（难度+）] → ... → [全部通关 → 胜利画面]
                                                                    ↓
                                                            [Game Over → 重新开始 / 返回主菜单]
```

### 核心动词

- **移动**：左右移动挡板
- **发球**：空格键将球从挡板上发射
- **接球**：预判球的轨迹，移动挡板到正确位置
- **吃道具**：用挡板接住掉落的道具

## 系统设计

### S1 · 球物理系统

球使用简化的反射物理（非真实物理引擎）：

- **初始角度**：从挡板出发，角度 60°-120°（朝上偏左或偏右）
- **墙壁反弹**：入射角 = 反射角
- **挡板反弹**：根据球撞击挡板的位置决定反射角
  - 撞击挡板中心 → 垂直弹回（90°）
  - 撞击挡板边缘 → 大角度弹出（30°-150°）
  - 公式：`reflect_angle = lerp(30, 150, hit_position_normalized)`
- **速度**：每关递增，关内不变（除道具影响）
- **防卡死**：如果球水平角度 < 15°，强制修正为 15°

### S2 · 砖块系统

| 砖块类型 | HP | 分数 | 颜色 | 特殊 |
|---|---|---|---|---|
| 普通 1HP | 1 | 10 | 蓝 | — |
| 普通 2HP | 2 | 20 | 绿 | 被击一次变色提示 |
| 普通 3HP | 3 | 30 | 橙 | 被击变色 2 次 |
| 不可破坏 | ∞ | 0 | 灰 | 只反弹球，不计入通关条件 |

通关条件：所有**可破坏**砖块 HP 降为 0。

### S3 · 道具系统

砖块被消灭时有概率掉落道具（默认 15%），道具从砖块位置自然下落，玩家需用挡板接住。

| 道具 | 图标色 | 效果 | 持续时间 |
|---|---|---|---|
| 加宽挡板 | 🟢 绿 | 挡板宽度 ×1.5 | 10 秒 |
| 缩窄挡板 | 🔴 红 | 挡板宽度 ×0.7 | 10 秒（负面道具）|
| 加速球 | 🟡 黄 | 球速 ×1.3 | 8 秒 |
| 多球 | 🔵 蓝 | 分裂出 2 个额外球 | 直到额外球丢失 |
| 额外生命 | 🩷 粉 | 生命 +1（最多 5）| 永久 |

同一时间只生效一个 buff/debuff（后拿的覆盖前一个，多球除外）。

### S4 · 生命与 Game Over

- 初始生命：3
- 最大生命：5
- 球落出屏幕底部 → 失去 1 生命
- 生命 = 0 → Game Over 画面（显示最终分数 + "重新开始" / "返回主菜单"）

### 主菜单

- 标题：**BREAKOUT**（大号像素字体）
- 按钮：Start / Quit
- 背景：缓慢移动的砖块动画

### Game Over / 通关画面

- **Game Over**：显示 "GAME OVER" + 最终分数 + Retry / Menu 按钮
- **通关**：显示 "YOU WIN!" + 最终分数 + 剩余生命奖励明细 + Menu 按钮

### 操控

| 输入 | 动作 |
|---|---|
| ← → / A D | 移动挡板 |
| Space | 发球（球粘在挡板上时）|
| Escape | 暂停 / 返回主菜单 |

### 无障碍

- 色彩对比度 ≥ 4.5:1（深色背景 + 亮色元素）
- 关键信息不依赖单一颜色（砖块 HP 用颜色 + 亮度双编码）
- 挡板移动速度足够快（500px/s），不需要极快反应

## 交付与验收

### 验收标准

| # | 标准 | 优先级 | 验证方式 |
|---|---|---|---|
| 1 | 挡板可左右移动，不越界 | P0 | 手动测试 |
| 2 | 球正确反弹（墙壁 + 挡板 + 砖块）| P0 | 手动测试 + 单元测试 |
| 3 | 砖块被击中 HP 正确减少 | P0 | 单元测试 |
| 4 | 通关条件正确（所有可破坏砖清零）| P0 | 集成测试 |
| 5 | 分数正确累加 | P0 | 单元测试 |
| 6 | 生命正确扣减 + Game Over 触发 | P0 | 集成测试 |
| 7 | 道具掉落 + 效果正确 | P1 | 手动测试 |
| 8 | 5 关全部可通关 | P1 | 手动通关测试 |
| 9 | 主菜单 / Game Over / 通关 界面流转正确 | P1 | 手动测试 |
| 10 | 球速随关卡递增 | P1 | 手动观察 + 数值表验证 |

### 风险

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|
| 球卡在水平弹跳死循环 | 中 | 玩家无法继续 | 防卡死机制（角度 < 15° 修正）|
| 道具负面体验 | 低 | 缩窄挡板导致挫败 | 缩窄持续时间短（10s）+ 出现概率可调 |
| 关卡难度跳跃过大 | 低 | 玩家在 L3 卡住 | 数值表可调，不用改代码 |

### 已知限制

- 本项目为流程验证用途，不追求商业品质
- 美术使用简单几何图形 / 纯色块，不含精细像素画
- 音效 / BGM 在 M4 阶段按需添加，M1-M3 静音
- 无存档系统（单局制）
- 无在线排行榜
