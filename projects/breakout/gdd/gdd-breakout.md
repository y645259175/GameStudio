# Breakout · 打砖块 GDD

## 概述

经典 Breakout 复刻：玩家操控屏幕底部的挡板，反弹球体撞击上方砖块阵列，消灭所有砖块即通关。

- **核心体验**：精准操控 + 连续消砖的爽快感
- **目标玩家**：休闲玩家 / 全年龄
- **类型**：2D Arcade / Breakout Clone
- **引擎**：Godot 4.x · GDScript
- **平台**：PC（Windows）
- **分辨率**：1280×720
- **预期游玩时长**：单局 3-5 分钟，全 5 关 15-25 分钟

## 玩法循环

### Core Loop（每秒）

```
[发球] → [球弹射] → [挡板接球/反弹] → [球击中砖块] → [砖块消失/掉道具] → [得分]
          ↓ 漏接
      [失去生命] → [剩余生命 > 0 ? 重新发球 : Game Over]
```

### Meta Loop（每关）

```
[开始关卡] → [消灭所有砖块] → [通关] → [下一关（难度+）] → ... → [全部通关 → 胜利画面]
                                                                    ↓
                                                            [Game Over → 重新开始 / 返回主菜单]
```

### 核心动词

- **移动**：左右移动挡板
- **发球**：空格键将球从挡板上发射
- **接球**：预判球的轨迹，移动挡板到正确位置
- **吃道具**：用挡板接住掉落的道具

## 系统设计

### S1 · 球物理系统

球使用简化的反射物理（非真实物理引擎）：

- **初始角度**：从挡板出发，角度 60°-120°（朝上偏左或偏右）
- **墙壁反弹**：入射角 = 反射角
- **挡板反弹**：根据球撞击挡板的位置决定反射角
  - 撞击挡板中心 → 垂直弹回（90°）
  - 撞击挡板边缘 → 大角度弹出（30°-150°）
  - 公式：`reflect_angle = lerp(30, 150, hit_position_normalized)`
- **速度**：每关递增，关内不变（除道具影响）
- **防卡死**：如果球水平角度 < 15°，强制修正为 15°

### S2 · 砖块系统

| 砖块类型 | HP | 分数 | 颜色 | 特殊 |
|---|---|---|---|---|
| 普通 1HP | 1 | 10 | 蓝 | — |
| 普通 2HP | 2 | 20 | 绿 | 被击一次变色提示 |
| 普通 3HP | 3 | 30 | 橙 | 被击变色 2 次 |
| 不可破坏 | ∞ | 0 | 灰 | 只反弹球，不计入通关条件 |

通关条件：所有**可破坏**砖块 HP 降为 0。

### S3 · 道具系统

砖块被消灭时有概率掉落道具（见下表掉率），道具从砖块位置自然下落，玩家需用挡板接住。

#### 道具一览

| 道具 | 图标 | 颜色 | 效果描述（玩家视角） | 持续时间 | 掉率权重 |
|---|---|---|---|---|---|
| 加宽挡板 | **宽** | 🟢 绿 `#16c79a` | 挡板变宽——更容易接球 | 10 秒 | 25% |
| 缩窄挡板 | **窄** | 🔴 红 `#e74c3c` | 挡板变窄——更难接球（负面） | 10 秒 | 15% |
| 加速球 | **快** | 🟡 橙 `#f5a623` | 球跑更快——更难反应 | 8 秒 | 20% |
| 消除 | **轰** | 🔵 蓝 `#3498db` | 立即清除一行砖块（⚠️ Phase 1 简化版，详见 [ADR-0001](../adr/ADR-0001-multi-ball-deferred.md)）| 一次性 | 20% |
| 额外生命 | **♥** | 🩷 粉 `#e91e63` | 生命 +1（最多 5） | 永久 | 20% |

#### 玩家感知设计（所有效果必须"看得到+看得懂"）

| 时机 | 表现 | 说明 |
|---|---|---|
| **道具掉落中** | 28×28 彩色方块，中间单字（宽/窄/快/轰/♥），整体 modulate.a 正弦脉冲 0.6↔1.0（2Hz）+ X 轴微抖 | 让玩家远距离识别道具种类 |
| **挡板拾取瞬间** | ① 道具方块消失 ② 挡板上方弹出中文反馈文字（如"挡板加宽！"），颜色同道具色，向上飘 60px + 1.5s 淡出 ③ 轻微屏幕震动 2px | 即时正反馈 |
| **buff/debuff 生效中** | 挡板正下方出现小色条（同道具色），宽度随剩余时间线性缩短直至消失 | 让玩家知道还剩多久 |
| **buff/debuff 结束** | 色条消失 + 挡板/球恢复原状，无额外动画 | 简洁 |
| **同类型覆盖** | 新 buff 重置计时条（重新满宽），不叠加强度 | 设计明确 |
| **反类型覆盖** | 如已有"宽"，拾取"窄"→ 宽立即消失，窄生效 | 后来者覆盖 |

#### 掉落规则

| 砖块类型 | 掉率 | 说明 |
|---|---|---|
| 1 HP（蓝） | 10% | 最多 → 掉率低 |
| 2 HP（绿） | 18% | — |
| 3 HP（橙） | 25% | 最少 → 掉率高 |
| 不可破坏 | 0% | 不掉落 |

单局最多掉 6 个道具（防满屏杂乱）。

同一时间只生效一个 buff/debuff（后拿的覆盖前一个；消除/+命是一次性不冲突）。

### S4 · 生命与 Game Over

- 初始生命：3
- 最大生命：5
- 球落出屏幕底部 → 失去 1 生命
- 生命 = 0 → Game Over 画面（显示最终分数 + "重新开始" / "返回主菜单"）

### 主菜单

- 标题：**BREAKOUT**（大号像素字体）
- 按钮：Start / Quit
- 背景：缓慢移动的砖块动画

### Game Over / 通关画面

- **Game Over**：显示 "GAME OVER" + 最终分数 + Retry / Menu 按钮
- **通关**：显示 "YOU WIN!" + 最终分数 + 剩余生命奖励明细 + Menu 按钮

### 操控

| 输入 | 动作 |
|---|---|
| ← → / A D | 移动挡板 |
| Space | 发球（球粘在挡板上时）|
| Escape | 暂停 / 返回主菜单 |

### 无障碍

- 色彩对比度 ≥ 4.5:1（深色背景 + 亮色元素）
- 关键信息不依赖单一颜色（砖块 HP 用颜色 + 亮度双编码）
- 挡板移动速度足够快（500px/s），不需要极快反应

### 风险

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|
| 球卡在水平弹跳死循环 | 中 | 玩家无法继续 | 防卡死机制（角度 < 15° 修正）|
| 道具负面体验 | 低 | 缩窄挡板导致挫败 | 缩窄持续时间短（10s）+ 出现概率可调 |
| 关卡难度跳跃过大 | 低 | 玩家在 L3 卡住 | 数值表可调，不用改代码 |
