# E1 · 核心玩法原型

**GDD 锚点**：§1 概述 · §2 玩法循环 · §4 S1 球物理 · §4 S2 砖块系统 · §4 S4 生命

**目标**：最小可玩版本——挡板移动、球弹射、砖块消灭、生命扣减、Game Over。

**验收标准**：
- [ ] 挡板左右移动，不越界
- [ ] 球从挡板发射，正确反弹（墙壁 + 挡板 + 砖块）
- [ ] 1HP 砖块被击中消失
- [ ] 球落出底部扣命
- [ ] 生命归零触发 Game Over
- [ ] 所有砖块消灭触发通关

**估算**：5-8 story points
**优先级**：P0
**里程碑**：M1
