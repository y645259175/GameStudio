# Breakout

经典打砖块复刻。GameStudio 全流程验证项目。

## 快速开始

1. 安装 Godot 4.x
2. 打开 `projects/breakout/` 目录
3. 运行主场景

## Smoke Checklist

| # | 检查项 | 状态 |
|---|---|---|
| 1 | 游戏能启动到主菜单 | `[ ]` |
| 2 | 挡板能左右移动 | `[ ]` |
| 3 | 球能弹射并碰砖块 | `[ ]` |
| 4 | 砖块被击中后消失 | `[ ]` |
| 5 | 分数正确累加 | `[ ]` |
| 6 | 生命耗尽后 Game Over | `[ ]` |
| 7 | 所有砖块消灭后通关 | `[ ]` |

## 技术栈

- 引擎：Godot 4.x LTS
- 语言：GDScript
- 分辨率：1280x720
