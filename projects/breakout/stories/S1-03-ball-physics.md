# S1-03 · 球弹射与反弹

**Epic**：E1 · 核心玩法原型
**GDD 锚点**：§4 S1 球物理系统 · §5 球速
**点数**：3

## User Story

作为玩家，我按空格发球后，球能正确弹射并在墙壁和挡板之间反弹。

## 验收标准

- [ ] 球初始粘在挡板上，按 Space 发射（角度 60°-120° 随机）
- [ ] 墙壁反弹：入射角 = 反射角（上、左、右三面墙）
- [ ] 挡板反弹：根据撞击位置决定角度（中心→90°，边缘→30°/150°）
- [ ] 球速 L1 = 300 px/s
- [ ] 防卡死：水平角度 < 15° 时强制修正
- [ ] 球落出底部 → 触发"失去生命"信号

## 技术备注

- 场景：`ball.tscn`（Area2D 或 CharacterBody2D + 自定义移动）
- 不使用 Godot 内置物理引擎的 RigidBody2D（反弹行为需精确控制）
- 信号：`ball_lost` → 通知 GameManager
