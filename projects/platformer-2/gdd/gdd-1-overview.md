# GDD §1 · Overview · 项目定位与范围

> 本章是 platformer-2 的"门面章"。任何后续章节（pillars / mechanics / 后续 §4-§8）都必须以本章定义的角色 / 世界观 / 范围为锚点。

---

## 概述

### 一句话定位（hook line）

**《Tower Tinker》** —— 一只独行的工坊学徒钻进废弃信号塔，用扳手、跳跃和管道直觉把锈死的塔体重新点亮。

### 类型定位

2D Side-Scrolling **Platformer + Pipe Puzzle** · 单人单局 · 关卡式（非开放）。

- 平台跳跃骨架来自经典手感（加减速、可变跳高）
- 在跳跃骨架上叠加一层 **管道拼接解谜**（玩家需要在塔内布管让信号/蒸汽流通）
- 在解谜骨架上叠加一层 **计时挑战**（信号塔每层有"压力计"，超时则机关锁死，需重置该层）

### 目标玩家

- 喜欢《蔚蓝》《空洞骑士》前段平台手感的玩家
- 喜欢《管道工》《Opus Magnum》式 spatial puzzle 的玩家
- 单局体验目标：M2 vertical slice 一关 8-12 分钟，3 个 puzzle 节点 + 1 个计时段。

### 与同世界观项目（bolt-1-1）的关系

platformer-2 与 bolt-1-1 共享"蒸汽朋克 + 信号塔"宇宙设定，**但没有任何角色 / 关卡 / 数值复用**：

| 维度 | bolt-1-1 | platformer-2 |
|---|---|---|
| 主角 | 机械豆 Bolty（任务者） | 工坊学徒 **Vex Pell**（修复者） |
| 玩法重心 | 横版逃亡 + 踩敌 | 塔内攀爬 + 管道拼图 + 计时 |
| 关卡形态 | Sector 1-1（地表横版推进） | Tower Beta-7（塔内多层向上推进） |
| 敌人 | 有（Mossroll / Shellpod） | 无（本作不做敌人，见 §1.5） |
| 失败模型 | 掉坑 / 接触敌人 / 超时 | 计时锁死 / 摔落 / puzzle 死锁 |
| 视角 | 横向单方向卷轴 | **纵向为主 + 短横向腔室** |

> 本章承诺：platformer-2 GDD 全文不出现 Bolty / Mossroll / Shellpod / Cache Box / Sector / Cog 等 bolt-1-1 specific 命名。

## 玩法循环

### 玩家视角的核心循环（30 秒一圈）

1. **观察**（3-5s）：进入新腔室，玩家看到一个未点亮的信号节点 + 散落在墙面的管道接口
2. **跳跃 / 攀爬**（5-10s）：用平台跳跃技巧到达管道接口，吃下"管段"（pipe segment）
3. **拼接**（5-10s）：在节点处把管段插好，让信号从入口流到出口
4. **触发计时**（10s 窗口）：节点点亮后开启计时，玩家必须在 10s 内攀到下一层入口
5. **回到 1**

### 玩家视角的关卡循环（一关 = 8-12 分钟）

```
入塔（30s 教学腔） → 节点A（拼图）→ 攀爬段A（计时）
                  → 节点B（拼图，引入"分叉管"）→ 攀爬段B（计时 + 平台 hazard）
                  → 节点C（拼图，3 段管道汇流）→ 顶端激活 → 关卡结算
```

### Meta 循环（M2 vertical slice 范围内）

- **没有外部 meta loop**（无存档进度、无解锁、无装备）
- 单关结束 → 显示通关时间 / 拼图最优解差值 → 回主菜单
- Meta 循环由 M3+ 的"塔群地图"承担，本章不展开

## 视觉与美术

### 风格基线（仅给方向，最终由 art-director 拍板）

- **整体调性**：蒸汽朋克 + 工坊学徒视角 → 偏暖、偏旧、偏潮湿；不偏军工冷峻
- **塔内主色板（指引值，最终见 art bible）**：
  - 锈红 #8B4A2B（结构件）
  - 黄铜 #C8995A（管道 / 节点未激活）
  - 蒸汽白 #E8E2D0（蒸汽 / 激活后管道光流）
  - 信号青 #5FB8B0（点亮后的节点辉光）
  - 阴影黑 #2A1E1A（背景塔骨架）
- **像素规格指引**：tile 32×32，主角 24×32，目标 1280×720 viewport 60 FPS

### 角色视觉骨架（仅大轮廓）

- **Vex Pell**：女性 / 中性向工坊学徒，棕色短工装 + 黄铜护目镜推到额头 + 腰间挂一把扳手
- 体型 24×32 像素，跳跃时护目镜会下垂遮眼（小细节，由 ux-designer 定时长）

### 反例（明确不做的视觉）

- ❌ 不做角色血条 / 数字伤害浮字（无敌人、无伤害概念）
- ❌ 不做炫酷粒子爆破（节点点亮用柔光晕开，不用爆炸）
- ❌ 不照搬 bolt-1-1 的 Cog 齿轮 HUD 风格

## 系统设计

### 玩家做什么（核心动词清单）

| 动词 | 出现频率 | 描述 |
|---|---|---|
| **Move** | 全程 | 左右移动 + 跳跃 |
| **Wall-cling** | 中频 | 短暂吸附墙面（不是 wall-jump，是抓握 0.6s）|
| **Pickup pipe** | 每节点 1-3 次 | 拾取场景中预设的管段 |
| **Place pipe** | 每节点 1-3 次 | 在节点 socket 上放置管段（4 朝向旋转）|
| **Activate node** | 每节点 1 次 | 拼图正确后按交互键，触发计时段 |
| **Reset node** | 失败时 | 长按 R 重置当前节点（不重置整关）|

> 完整状态机和数值见 §3 mechanics。

### 玩家不做什么（明确边界）

- ❌ 不攻击 / 不击杀 / 不踩敌（本作没有敌人）
- ❌ 不收集货币 / 不升级 / 不解锁能力
- ❌ 不切场景 / 不切角色 / 不切武器
- ❌ 不与 NPC 对话（M2 范围内 0 NPC）
- ❌ 不存档（M2 单关一次过，死亡回当前节点起点）

### 子系统拆解（指针）

| 子系统 | 主章节 | 一句话职责 |
|---|---|---|
| 移动 / 跳跃 | §3.移动 | 平台手感骨架 |
| 管道拼图 | §3.解谜 | spatial puzzle 主玩法 |
| 计时挑战 | §3.计时 | 节点激活后的攀爬压力 |
| 状态机 | §3.状态机 | player / world / node 三层 FSM |
| HUD | §7.UX（后续章节） | 计时条 + 当前节点提示 |

## 数值与平衡

本章是 overview，**不定义具体玩法数值**（玩法数值见 §3 mechanics、§5 数值与平衡）。

但本章定义"项目级元数值"作为后续章节的硬约束：

| 字段 | 基准值 | 字段路径（数据驱动）|
|---|---|---|
| target_fps | 60 | `data/project.json` → `performance.target_fps` |
| viewport_size | 1280×720 | `data/project.json` → `display.viewport` |
| tile_size | 32 | `data/project.json` → `display.tile_size` |
| target_level_duration_sec | 600（10 分钟基准）| `data/project.json` → `pacing.target_level_sec` |
| max_nodes_per_level | 3（M2 vertical slice）| `data/project.json` → `pacing.max_nodes_per_level` |
| death_to_respawn_sec | 1.5 | `data/project.json` → `pacing.death_to_respawn_sec` |

> 实际数值文件由 engineer agent 在 M1 落盘到 `data/project.json`，本章只规定字段名 + 基准值。

### 平衡假设

1. 玩家"看到节点 → 完成拼图"中位时间 = **45-90 秒**。超过 90s 说明拼图过难，需要拆分。
2. 玩家"激活节点 → 到达下一层入口"中位时间 = **6-9 秒**（计时窗口 10s 即从此推出）
3. 单次摔落代价 ≤ **3 秒**（重生 1.5s + 玩家定位 1.5s），避免挫败感累积

## 内容与节奏

### M0-M2 范围控制（强约束）

| 里程碑 | 范围 | 不在范围 |
|---|---|---|
| **M0**（GDD + 骨架） | 本 GDD §1-§3 三章 + 项目骨架 | §4-§8 / 任何代码 / 任何美术资产 |
| **M1**（核心循环 prototype） | 移动 + 跳跃 + 1 个 dummy 拼图节点 + 计时 | 完整关卡 / 视觉资产 / 音效 |
| **M2**（vertical slice） | 1 个完整关卡（3 节点）+ 占位美术 + 计时 HUD | 第二关 / 配置菜单 / 多语言 / 存档 |

### M2 关卡叙事节奏（一关 8-12 分钟）

| 段 | 时长 | 玩家心理 | 设计触发 |
|---|---|---|---|
| 0-30s | 入塔教学腔 | "我能跳，我能抓墙" | 强制必经的小跳 + wall-cling 段 |
| 30s-3min | 节点 A | "我把管子接上了，灯亮了！" | 单段直管，2 朝向即可解 |
| 3-4min | 攀爬段 A | "10 秒够吗？刚好够！" | 直上型攀爬，无 hazard |
| 4-6min | 节点 B | "原来管子要分叉" | T 形 + 弯管，4 朝向 |
| 6-7min | 攀爬段 B | "有蒸汽喷孔挡路！" | 加入 hazard：周期性蒸汽喷孔 |
| 7-10min | 节点 C | "三股要汇流到一个出口" | 3 输入 1 输出，最难 |
| 10-12min | 顶端激活 + 结算 | "我让信号塔活了" | 全塔点亮过场 + 时间结算 |

### 内容预算（M2 vertical slice 完成定义）

- 关卡数：1
- 节点数：3
- 管段类型：直管 / 弯管（90°）/ T 形分叉，共 3 类
- Hazard 类型：1（周期性蒸汽喷孔）
- 角色：1（Vex Pell）
- 美术资产数（占位 OK）：tile set 1 套 + 角色 spritesheet 1 张 + 管段 4 张图 + 节点 3 张图 + 蒸汽特效 1 个

## UX 与 HUD

> 本章只列 overview 级别的 HUD 元素清单。详细 UI 流转 / 控件位置 / 交互动画交由 ux-designer 在 ux-spec 文档中定义。

### M2 必须出现的 HUD 元素

| 元素 | 位置（指引）| 触发 / 显示规则 |
|---|---|---|
| **计时条** | 屏幕顶部居中 | 节点激活后显示，10s 倒计时；未激活时隐藏 |
| **当前节点提示** | 屏幕右上 | 进入节点交互范围时淡入"按 E 拼接" |
| **节点完成度** | 节点本体上方浮动 | "1/3" / "2/3" / "3/3" 形式（仅多输入节点）|
| **重置提示** | 屏幕中央 | 按住 R 时显示进度环（0.8s）|
| **通关结算** | 全屏 | 通关时显示总用时 + 各节点最优解差值 |

### M2 不做的 HUD（明确）

- ❌ 不做血条 / 命值（无伤害模型）
- ❌ 不做小地图 / 塔内导航（关卡线性向上）
- ❌ 不做暂停菜单（仅 ESC 直接回主菜单）
- ❌ 不做控制说明覆盖层（教学腔承担）

### 输入设备支持（M2 范围）

- 键盘 + 鼠标（鼠标仅用于管段旋转，可选）
- Xbox 手柄（基础四方向 + A 跳 + X 交互 + LB 拾取 + RB 旋转 + Start 重置）
- 不支持触屏 / 不支持自定义键位（M3+）

### 风险登记

| 风险 | 影响 | 缓解 |
|---|---|---|
| 管道拼图设计空间过浅 → 3 个节点同质化 | M2 体验单薄 | §3 引入"分叉管 / 汇流"递进，每节点引入 1 新元素 |
| 计时窗口太紧 → 玩家挫败 | 流失 | 10s 是基准，§3 给出可调字段，M1 prototype 期允许 +20% 容差 |
| 角色 Vex Pell 与 Bolty 视觉混淆 | IP / 同质化 | art-director 必须在 art bible 显式做 silhouette 对比 |
| 无敌人 → 张力不足 | 玩家觉得无聊 | 用计时 + hazard（蒸汽喷孔）替代敌人提供压力源 |
