## 1. 设计精神

### 1.1 美术目标

- **风格**：水墨写意（鬼谷八荒 + 中国独立游戏典型审美）
- **目标心智**：玩家看 1 秒能感受"修仙 + 经营 + 沉淀感"
- **商业化基础**：M3 美术达到"能进 Steam 商店页"水准（GDD-01 §7.1 M3 纪律）

### 1.2 三条美术总原则

1. **风格统一 > 单图精度** —— 30 张风格一致的图比 5 张高精度孤儿图更值钱
2. **canonical key 守门** —— 关键角色立绘走"风格基准 + 量产参考"双层评审
3. **AI 辅助 + 修绘** —— 立绘 AI 生成 + 修绘流程；UI / 图标手绘 / 设计师做


## 5. Canonical Key 评审流程（关键守门机制）

### 5.1 用途

让"风格一致性"在量产前先建立基准。关键角色（门主 / 初始弟子 / 关键 NPC）的立绘必须通过 canonical key gate 才能进游戏。

### 5.2 流程

```
Step 1 · 准备角色描述（性别 / 年龄 / 境界 / 性格 / 服饰）
Step 2 · art-asset-pipeline 生成 3-5 个候选
Step 3 · art-director agent 评审
  ├─ 风格契合度（与 key visual 一致？）
  ├─ 角色辨识度（看一眼能想起人物？）
  ├─ 技术质量（无明显 AI 瑕疵？）
  └─ 修绘需求清单
Step 4 · 设计师修绘 / 重生成
Step 5 · art-director 二次评审 → 通过 → 入 art/canonical/
Step 6 · 该角色后续所有立绘变体（不同表情 / 服饰）以此为基准
```

### 5.3 评审标准

| 维度 | APPROVE 标准 |
|---|---|
| 风格 | 笔触 / 配色 / 整体调性与 key visual 一致 |
| 角色 | 三处可识别特征（如服饰颜色 / 发型 / 配饰）一致 |
| 技术 | 无明显 AI 解剖错误 / 手指畸形 / 多余物品 |
| 商业化 | 单看一张能用作 Steam 商店头像 |

### 5.4 失败回路

不通过 → art-director 写"修绘清单"返回设计师 → 改完重审。最多 3 轮，3 轮不过升级到用户决策。

## 7. UI 视觉规范

### 7.1 UI 信息层级

```
顶栏（持续可见）：资源数字 + 时间 + 弟子数
主区（场景态）：宗门主界面 / 历练地图 / 战斗 UI
弹窗（临时）：建筑详情 / 弟子详情 / 事件 / 选项
通知（短暂）：突破成功 / 建筑完成 / 资源警告
```

### 7.2 关键 UI 风格

- **宣纸底 + 墨黑边框** —— 所有面板基底
- **印章红 / 古铜色强调** —— 重要数字 / 按钮高亮
- **毛笔字体大标题 + 宋体正文** —— 古今搭配
- **小印章作 icon 装饰** —— 章节标题 / 重要按钮

### 7.3 UI Shader（M2 期实装）

- 宣纸纹理叠加 shader（保持各分辨率下纹理粒度一致）
- 印章红色调（可控饱和度 + 暗角）
- 毛笔字体描边 shader（M5 主线 CG 文字用）

### 7.4 响应式

- 基准：1920×1080
- 兼容：1280×720（最低）/ 2560×1440 / 21:9 宽屏
- 锚点：核心 UI 居中或四角锚定，避免拉伸畸形
