## 1. 设计精神

### 1.1 数值层的定位

> 哲学（GDD-01 §6.12 延伸）：**公式骨架在各玩法章（GDD-03/04/05），具体系数在 GDD-06**。

| 层 | 谁持有 | 例 |
|---|---|---|
| 公式骨架 | 玩法章 | GDD-04：`monthly_gain = base_speed × (1+Σa·root) × ...` |
| **具体系数** | **GDD-06（本章）** | `base_speed` 各境界取值 / `a` 系数区间 / 边际递减曲线参数 |
| 运行时数据 | `data/table/*.xlsx` | 烘焙后的实际配表 |

**纪律**：

- 任何"将来可能为平衡调整"的数字都在 GDD-06 定义 + 落配表，**不写死在代码**（记忆 §元教训 HH）
- GDD-06 改一个系数 → 烘焙 → 重测，不动任何玩法章公式
- M3 所有数值是**占位基线**，M3 实玩后按"核心循环手感"校准

### 1.2 数值设计的三条总原则

1. **边际递减贯穿全局**（GDD-01 §2.3）：任何"持续投入"都快速衰减，倒逼玩家循环切换行为
2. **经营压力 > 自然产出**：月俸 + 维护费略大于宗门自给，倒逼玩家出门历练（GDD-05 §11）
3. **深度 = 收益曲线**：历练越深、境界越高，收益档次拉开（驱动玩家冒险）

### 1.3 M3 数值标定的目标手感

| 维度 | M3 目标 |
|---|---|
| 单局时长 | 前期 ~20 分钟 / 后期 ~60 分钟（GDD-01）|
| 境界进度 | 单局炼气小境界递进 1-3 次，**可能** 1 次大突破 |
| 边际递减感知 | 第 3 个月明显感到"光闭关不够用"（GDD-01 M3-4 验收）|
| 经济压力 | 玩家不出门历练 → 5-8 月后灵石入不敷出 |

| 汇 | 耗什么 | 节奏 | 压力强度 |
|---|---|---|---|
| 月俸 | 灵石 | 每月（弟子数 × 月俸）| **核心压力源**（§5）|
| 建筑维护（M4）| 灵石 | 每月 | 中 |

## 5. 弟子月俸与维护成本（经营压力源）

### 5.1 月俸公式

```
宗门月俸总支出 = Σ disciple_salary(realm)   （对每个在宗弟子）

disciple_salary(realm):
  炼气：5 灵石/月
  筑基：15 灵石/月
  金丹：50 灵石/月
  元婴：150 灵石/月
  化神：400 灵石/月
```

> 境界越高的弟子月俸越贵——高战力是有成本的。这防止"无脑囤一堆高境界弟子"。

### 5.2 月俸触发（GDD-05 月节拍）

```
月节拍：
  └─ total = Σ disciple_salary(c.realm) for c in sect.members
      └─ InventoryService.consume("spirit_stone", total)
          └─ 不足时：触发 "月俸不足" 危机（M4 事件）；M3 仅 UI 红字警告 + 弟子不流失
```

> M3 月俸不足**不导致弟子流失**（避免新手挫败）；M4 加"欠俸→忠诚度下降→叛宗"链。

### 5.3 维护成本（M4，M3 占位）

建筑每月维护费（灵石）= 建筑等级 × 维护系数。M3 不收维护费（简化），M4 启用。

### 5.4 宗门声望 reputation

| 量 | 影响 | M3 取值 |
|---|---|---|
| reputation | `auto_recruit_chance`（自动来投概率）| 初始 100 |
| 提升来源 | 弟子突破 / 历练成就 / 主线（M5）| 突破 +10 / 历练里程碑 +5 |
| `auto_recruit_chance` | = clamp(reputation / 2000, 0.02, 0.30) 每月 | rep 100 → 5%/月 |

## 6. 成长数值标定（GDD-04 公式系数）

> 收拢 GDD-04 所有"GDD-06 平衡"占位。以下为 M3 占位基线。

### 6.1 经验阈值 `experience_threshold(realm, sub_realm)`

```
experience_threshold = base_threshold(realm) × growth_curve(sub_realm)

base_threshold:  炼气=100 / 筑基=500 / 金丹=2500 / 元婴=12000 / 化神=60000
growth_curve(sub):  sub^1.3   （1层=1.0 ... 9层≈16.0）
```

> M3 主要体验炼气境界：炼气 1 层阈值 100，9 层阈值 ≈ 1600。单局闭关递进 1-3 个小境界。

### 6.2 修炼速度 `base_speed` 与灵根系数 `a`

```
monthly_gain = base_speed × (1 + Σ aᵢ·effective_rootᵢ) × cultivation_multiplier × diminishing

base_speed(realm):  炼气=15 / 筑基=40 / 金丹=120 / 元婴=400 / 化神=1200（经验/月）
aᵢ 区间:  单灵根 0.01~0.10；单功法 Σa 约束 0.05~0.20（本章接管自原 GDD-02 §1.7 平衡假设）
cultivation_multiplier:  建筑/buff modifier 之和（修炼塔 +20%~50% 等）
```

**校验**（炼气 1 层，火 10 单灵根，纯火功法 a=0.08，无 buff）：
```
monthly_gain = 15 × (1 + 0.08×10) × 1.0 × 1.0 = 15 × 1.8 = 27 经验/月
→ 炼气 1 层阈值 100 / 27 ≈ 3.7 月升 1 级
→ 进修炼塔 lv1（+20%）：27×1.2=32.4 → ≈3.1 月。符合"单局递进 1-3 级"
```

### 6.3 修为分 `base_monthly_score`

```
monthly_score_gain = base_monthly_score × (insight/100) × bottleneck_diminishing

base_monthly_score = 8（全局常量）
insight 默认 100 → 系数 1.0
```

### 6.4 突破概率系数

```
基础概率 = (base_score + MAX(cultivation_score,10) + root_score + insight_score) / difficulty_score

base_score(功法×境界):  炼气→筑基 普通功法 = 20
difficulty_score(功法×境界):  炼气→筑基 = 100
root_score = Σ 绑定灵根点数（如火 10 = 10）
insight_score = (insight-100)/10
```

**校验**（炼气9层瓶颈打磨 10 月，火 10，悟性 100，突破丹+10%）：
```
cultivation_score ≈ 8×1.0×(10月内递减) ≈ 70
基础概率 = (20 + 70 + 10 + 0) / 100 = 1.00 → clamp → 但加突破丹其实已满
若仅打磨 3 月：score≈24 → (20+24+10)/100 = 0.54 → +突破丹 0.10 = 0.64
```
> 设计意图：瓶颈打磨 3 月约 5 成把握，10 月接近必成。玩家可选"赌早突破"或"稳打磨"。

### 6.5 寿元加成 `lifespan_bonus(realm)`

| 境界 | 加成（年）| 月 |
|---|---|---|
| 凡人起点 | 50-70（随机）| 600-840 |
| 炼气 | +80-100 | +960-1200 |
| 筑基 | +80-100 | 同上 |
| 金丹 / 元婴 / 化神 | +80-100 each | 同上 |
| 飞升 | ∞ | — |

### 6.6 Buff 数值（GDD-04 §7 库）

| buff_id | 数值 | 时长 |
|---|---|---|
| `cultivation/qi_acceleration`（聚气丹）| 闭关 +20% | 30 天 |

## 7. 战斗数值标定（GDD-03 §6 系数）

### 7.1 战力公式系数

```
final_power = base_power × (1 + Σbuff_mod) × (1 + element_bonus)

base_power(境界基线):  炼气=100 / 筑基=600 / 金丹=4000 / 元婴=25000 / 化神=150000
```
> **每大境界约 5-7 倍跳变**——体现"1 大境界差 = 5-10 倍数值差"的修仙碾压感（设计语义见 GDD-02 §3.5）。

### 7.3 胜负判定

| 参数 | 值 |
|---|---|
| `power_ratio_dominate`（碾压阈值）| 1.2 |
| 势均力敌 RNG 区间 | 0.83x ~ 1.2x |
| ESCAPED 概率（escape_allowed 时）| 按 power 劣势比例，最高 40% |

### 7.4 LootTable 深度档次曲线（GDD-03 §1 核心）

> GDD-03 §1.8 转交的"节点池产物档次曲线"——浅层给低档、深层给高档。

| 节点深度 | 灵石档 | 材料档 | 稀有掉落 |

| d=0-1（浅）| 20-50 | 木/石/草 | 无 |

## 8. 宗门建筑数值（GDD-05 §4.5 收拢确认）

> GDD-05 §4.5 已列建筑总表，本节确认其经济合理性 + 总投资。

### 8.1 建造成本递增规律

```
build_cost(lv) ≈ build_cost(lv1) × 3^(lv-1)
  例：修炼塔 lv1=200 / lv2=600 / lv3=1800
```
> 每级 ×3 是边际递减的成本侧体现（§4 总账）。

### 8.2 全建筑升满总投资

| 建筑 | lv1+lv2+lv3 灵石 | 材料 |
|---|---|---|
| 主殿 | 0+800+2500 = 3300 | 70 石料 |
| 弟子居所 | 0+300+1000 = 1300 | 45 木料 |
| 修炼塔 | 200+600+1800 = 2600 | — |
| 藏书阁 | 200+600+1800 = 2600 | — |
| 丹房 | 250+700+2000 = 2950 | — |
| **合计** | **≈ 12750 灵石** | 70 石 + 45 木 |

> 对应玩家需 ~15-25 次历练积累（按 §7.4 单次历练 200-500 灵石）。M3 单局通常只升 2-3 个建筑到 lv2，全升满是多局目标。

### 8.3 容量曲线（GDD-05 §7.5 确认）

弟子居所 lv1=6 / lv2=10 / lv3=15 是宗门人口硬上限。修炼塔/藏书阁容量 < 居所容量——保证"不是所有弟子都能同时闭关"，逼玩家取舍（部分弟子去历练/派遣）。

## 9. 加工链（炼丹经济性）

### 9.1 炼丹投入产出比

| 配方 | 投入 | 产出 | 成功率 | 期望性价比 |
|---|---|---|---|---|
| 聚气丹 | 灵草×2（自产）| ×3 丹 | 0.90 | 高（自给原料）|
| 疗伤丹 | 灵草×1 兽血×1 | ×2 丹 | 0.80 | 中 |
| 突破丹 | 灵草×3 妖丹×1 | ×1 丹 | 0.60 | 低（妖丹稀有）|
| 火灵根丹 | 火精×2 妖丹×2 | ×1 丹 | 0.45 | 极低（赌灵根永久 +1）|
| 寿元丹 | 千年灵芝×1 妖丹×3 | ×1 丹 | 0.30 | 极低（M4）|

### 9.2 加工链设计意图

```
基础链（自给）：丹房月产灵草 → 聚气丹 → 闭关加速 → 修炼更快
高级链（依赖历练）：历练取妖丹/火精 → 突破丹/灵根丹 → 关键节点强化
```

> 基础链让宗门有"自循环感"，高级链把炼丹与历练绑定——呼应核心循环（§10）。

### 9.3 资源转化率纪律

- 自产原料的丹药（聚气丹）成功率高、性价比高 → 鼓励常态使用
- 稀有原料的丹药（灵根丹）成功率低 → "稀有材料 + 赌一把"的张力
- 失败退回 50% 材料（`fail_recovery_rate`）→ 降低挫败但不消除风险

## 10. 核心循环经济模型（M3 一局推演）

### 10.1 玩家循环的数值闭环

```
① 历练（10-60 min）→ 得 200-500 灵石 + 材料 + 妖丹
② 回宗投资：升建筑（脉冲大额）/ 炼丹（中额）/ 突破（大额）
③ 月俸持续流出（弟子数 × 境界月俸）
④ 闭关修炼（建筑加速）→ 经验↑ → 境界↑ → 战力↑
⑤ 战力↑ → 能打更深历练 → 回到 ①，收益档次更高
```

### 10.2 经济压力曲线（M3 标定目标）

```
假设：开局 3 弟子（炼气，月俸 5×3=15/月），初始 500 灵石

不出门历练情景：
  月 1-3：升修炼塔 lv1（-200）+ 建丹房（-250）→ 余 50 - 月俸 45 ≈ 入不敷出
  月 4+：灵石转负 → UI 红字警告 → 玩家被迫出门

出门历练情景：
  每 2-3 月出门 1 次 → +300-500 灵石 → 覆盖月俸 + 留投资余量 → 良性循环
```

> 设计临界点：**纯宗门自给约 5-8 月转负**（§3.4）。M3 实玩校准这个临界——太松玩家不出门，太紧玩家压力过大。

### 10.3 境界成长节奏（M3 单局）

```
开局炼气 1 层 → 修炼塔 lv1 闭关 → 约 3 月/小境界
单局 20-60 分钟（若干月节拍）→ 炼气递进 1-3 层
攒够修为分 + 突破丹 → 可能 1 次大突破（炼气9→筑基1）
```

### 10.4 平衡假设（待 M3 实玩验证）

| 假设 | 数值 | 验证方式 |
|---|---|---|
| 单次历练净收益 | 200-500 灵石 | M3 smoke 实测 |
| 自给转负时间 | 5-8 月 | M3 实玩计时 |
| 边际递减感知 | 第 3 月明显 | M3-4 验收（用户实玩反馈）|
| 单局境界进度 | 1-3 小境界 + 可能 1 大突破 | M3 smoke |
