# GDD · Mario 1-1 复刻

> 本文档为渐进式策划，从框架到血肉到细节。当前版本：0.1-framework（每节子项占位）。
>
> 推进路径：0.1 框架 → 0.5 血肉 → 1.0 完整细节。

---

## 1. 概述

### 1.1 项目定位
本节描述项目目标（教学性复刻 / 横版平台跳跃单关卡）与目标受众。

### 1.2 设计支柱（Design Pillars）
本节锁定 3 条不可妥协的设计支柱，作为后续所有决策的对照锚。

### 1.3 核心体验（Core Fantasy）
本节描述玩家在 60 秒内应感受到的核心情绪与操作快感。

### 1.4 范围声明（Scope Statement）
本节明确"做什么 / 不做什么"，例如只复刻 World 1-1，不做存档、不做多人。

### 1.5 参考与对标
本节列出参考作品（NES Super Mario Bros. 1-1）与对标维度。

---

## 2. 玩法循环

### 2.1 Core Loop（秒级）
本节描述"观察→移动→跳跃→踩敌/吃道具→推进"的最小操作循环。

### 2.2 Mid Loop（关卡级）
本节描述从出生点到旗杆的整段关卡推进循环。

### 2.3 失败与重试循环
本节描述死亡判定 → 重生 → 再次挑战的节奏。

### 2.4 奖励循环
本节描述金币 / 蘑菇 / 火花 / 1UP 的获取节奏与情绪反馈。

### 2.5 学习曲线（Teaching Beats）
本节描述关卡前 10 秒如何无文字教会玩家"走 / 跳 / 踩 / 顶砖"。

---

## 3. 视觉与美术

### 3.1 整体艺术风格
本节描述像素风格、分辨率基准与"NES 复古 + 现代清晰度"的平衡方向。

### 3.2 色板（Palette）
本节定义全局色板表（背景蓝 / 地面棕 / 角色红等），落 `data/palette.json`。

### 3.3 角色精灵（Character Sprites）
本节列出马里奥三态精灵集（小 / 大 / 火力）的占位规格。

### 3.4 敌人精灵（Enemy Sprites）
本节列出 Goomba / Koopa Troopa 等敌人精灵规格。

### 3.5 关卡 Tileset
本节定义地面 / 砖块 / 问号块 / 管道 / 旗杆 / 城堡 / 云山树丛背景的图块表。

### 3.6 动画规格表（VFX）
本节以 VFX-XX 编号统一登记所有动画（如 VFX-01 跳跃 / VFX-02 死亡 / VFX-03 吃蘑菇变身），具体帧数后填。

### 3.7 UI 视觉
本节描述 HUD / 字体 / 数字样式的视觉规范。

### 3.8 过场与转场
本节描述开场、死亡黑屏、过关旗杆下滑与城堡进入的过场表现。

## 4. 系统设计

### S1 · 角色控制（输入 / 移动 / 跳跃 / 跑步）
本节描述马里奥的输入映射、加减速、跳跃手感与跑步切换。

### S2 · 物理系统（重力 / 碰撞 / 摩擦）
本节描述世界级物理规则、碰撞盒约定与表面摩擦差异。

### S3 · 状态系统（小 / 大 / 火力 / 无敌 / 死亡）
本节描述马里奥形态状态机及其转移条件。

### S4 · 敌人系统（Goomba / Koopa / 行为模式）
本节描述敌人 AI、巡逻、被踩、被火球击中的行为分支。

### S5 · 道具系统（蘑菇 / 火花 / 星星 / 1UP）
本节描述道具产出、移动行为、拾取效果与状态联动。

### S6 · 关卡元素（砖块 / 问号块 / 管道 / 金币 / 旗杆）
本节描述各类可交互关卡元素的触发规则与产出。

### S7 · 摄像机系统
本节描述横向跟随、不可回退、边界夹取的摄像机规则。

### S8 · 计分与生命系统
本节描述金币 / 击杀 / 时间 / 通关得分与剩余生命的累加规则。

### S9 · 关卡流程（出生 / 检查点 / 旗杆 / 城堡）
本节描述一关从开始到结束的状态机。
