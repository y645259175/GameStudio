# 无障碍设计 · ${PROJECT_NAME}

## 适用标准

WCAG 2.1 AA（最低）/ AAA（目标）

## 视觉

### 色彩

| 检查项 | 要求 | 状态 |
|---|---|---|
| 常规文本对比度 | ≥ 4.5:1 | `[ ]` |
| 大文本对比度 | ≥ 3:1 | `[ ]` |
| 非文本对比度 | ≥ 3:1 | `[ ]` |
| 色盲友好 | 不依赖单一色彩传达信息 | `[ ]` |
| 色觉异常模式 | 提供切换 | `[ ]` |

### 字体

| 检查项 | 要求 | 状态 |
|---|---|---|
| 最小字号（PC） | ≥ 14pt | `[ ]` |
| 最小字号（移动端） | ≥ 16pt | `[ ]` |
| 可缩放 | 200% 无溢出 | `[ ]` |

## 交互

### 输入

| 检查项 | 要求 | 状态 |
|---|---|---|
| 键盘可达 | 所有操作可键盘完成 | `[ ]` |
| 焦点可见 | 焦点指示器清晰 | `[ ]` |
| 焦点顺序 | 逻辑顺序（左→右 / 上→下）| `[ ]` |
| 操作时限 | 可调整 / 可关闭 | `[ ]` |
| 震动反馈 | 可关闭 | `[ ]` |

### 导航

| 检查项 | 要求 | 状态 |
|---|---|---|
| 一致导航 | 相同功能相同位置 | `[ ]` |
| 跳转链接 | 可跳过重复内容 | `[ ]` |
| 面包屑 | 层级 ≤ 3 时提供 | `[ ]` |

## 音频

| 检查项 | 要求 | 状态 |
|---|---|---|
| 字幕 | 所有语音提供字幕 | `[ ]` |
| 音量独立控制 | BGM / SFX / 语音 可分别调节 | `[ ]` |
| 音频描述 | 关键视觉信息提供音频提示 | `[ ]` |

## 认知

| 检查项 | 要求 | 状态 |
|---|---|---|
| 语言简洁 | 指令 ≤ 2 步 | `[ ]` |
| 错误提示 | 具体说明问题 + 修复建议 | `[ ]` |
| 确认机制 | 不可逆操作需二次确认 | `[ ]` |
| 进度保存 | 自动存档 / 手动存档 | `[ ]` |

| 3 | 屏幕阅读器 | NVDA / VoiceOver | `[ ]` |
| 4 | 缩放 200% | 浏览器缩放 | `[ ]` |
