# Calibration · art-director · GOOD-02

## 前置场景
- 新项目 M0 阶段，需要前置定调（先定风格再生成资产）
- PROJECT.md 定义主题"蒸汽朋克 + 信号塔"
- 同世界观已有另一个项目的 style-guide（可参考但不照抄）

## 条件
- Mode: DRAFT style-guide
- 必须与已有项目差异化（色相差 ≥ 60°）

## 产出摘要
- tone_statement: "Rusted Brass Stillness · 锈蚀黄铜中的静谧"
- color_palette: 5 色全有 hex + rgb + usage（主色 #5C7A6E Verdigris Green）
- pixel_density: {tile_size: "32x32", character_size: "32x48", ui_font_size: "16px"}
- character_design: {protagonist: "Vex Pell", key_props: ["信号塔", "管道齿轮"], npcs_enemies: 3 个一句话描述}
- asset_production_sop: 含 "reference-based" + "image_edit" 关键词
- 与已有项目主色色相差 = 110°（> 60° 阈值）

## 为什么是 GOOD
1. 5 色全有 hex（不是"深绿色"这种模糊描述）
2. pixel_density 全具体（不是"待定"）
3. 主动检查与已有项目色相差（差异化意识）
4. asset_production_sop 明确写了 reference-based 流程（防 AP-03）

## 通用教训
- style-guide 的核心价值在"精确到 hex / px"——让 pipeline 有据可依
- 差异化检查是多项目工作室的必须步骤
