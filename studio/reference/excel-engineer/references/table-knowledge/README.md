## 维护规则

1. 每次改动一张**没有知识卡片**的表，完成后主动提议新建卡片
2. 每次改动一张**已有知识卡片**的表，如发现卡片内容有误或遗漏，主动提议更新
3. 知识卡片保持精简实用，重点记录：必填字段、TID列、对应文本表、关联表、踩坑记录
4. **项目专用决策不写在通用卡片里**，集中放在对应项目的 SOP skill 中（如 SLGX/SFK 的 `hero-config` skill）
5. 每次变更知识卡片后，在 [CHANGELOG.md](CHANGELOG.md) 中追加记录（含记录人）
