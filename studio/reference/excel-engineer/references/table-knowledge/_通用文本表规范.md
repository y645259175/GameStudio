# 通用文本表规范

> 适用于所有 `xls/Text/W_文本表_*.xlsx` 文件的通用规则。

## 文本表位置

`common/excel/xls/Text/`

## 表头结构

| 行 | 说明 |
|----|------|
| Row 1 | convert 声明 + `DONT_CONVERT_TO_KEY` 标记 |
| Row 2 | 语言标识（key, zh_CN, ...） |
| Row 3 | 语言标识 + 描述列 |
| Row 4+ | 数据行 |

## 语言列分布

| 列 | 语言标识 | 说明 |
|----|---------|------|
| Col 1 | key | TID key（主键） |
| Col 2 | zh_CN | 简体中文 |
| Col 3 | 描述 | 描述备注列（非导出） |
| Col 4 | DNT | 不要翻译标记 |
| Col 5 | zh_GL | 简体中文备份 |
| Col 6 | 繁体中文 | |
| Col 7 | EN | 英文 |
| Col 8 | JP | 日文 |
| Col 9 | KR | 韩文 |

## 多语言填写规则

新增 TID 时，**默认必须填写**以下列：

| 列 | 语言 | 是否必填 | 说明 |
|----|------|---------|------|
| Col 1 | key | 必填 | TID key |
| Col 2 | zh_CN | 必填 | 简体中文内容 |
| Col 5 | zh_GL | 必填 | 与 zh_CN 内容相同 |
| Col 7 | EN | **询问用户** | 每次新增文本前需询问用户是否需要翻译英文 |

其他语言列（繁体 Col 6、日文 Col 8、韩文 Col 9）如无特殊要求不填写。

## 文本表不导出

文本表修改后**不需要手动导出**，由下游流水线统一处理。修改确认无误后直接提交 xlsx 即可。

## 注意事项

- 必须使用 win32com 操作，禁止用 openpyxl 保存
- 新增 TID 时追加到对应表的末尾（在最后一条数据行之后）
- 如需插入行（而非追加），注意不要破坏已有行的行号引用
