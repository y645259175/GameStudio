## 多语言填写规则（沿用通用规范）

| 列 | 语言 | 是否必填 | 说明 |
|----|------|---------|------|
| Col 1 | key | 必填 | TID key |

## ⚠️ 关键约束：元数据列不要碰

**Col 22-30** 的 9 个元数据列（来源 Excel / 来源 Sheet / 来源 pbin / 来源 column / 来源列注释 / 文本内数字 / 翻译合入时间 / 中文修改时间 / 原始 th_TH）的 row2 注明**"自动填充，不要手动修改"**。这些列由翻译/构建流水线自动维护。
