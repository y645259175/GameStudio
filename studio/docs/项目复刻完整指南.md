## 3. 手动补齐：Godot 引擎（不在 git 中）

引擎二进制 **164.4 MB**，被 `.gitignore` 排除。

1. 下载 Godot 4.6.2 stable：https://godotengine.org/download/archive/4.6.2-stable/
2. 在项目根目录建立如下结构并放入对应平台的可执行文件：
   ```
   engine/
   └── Godot/
       ├── Godot_v4.6.2-stable_win64.exe     ← Windows（当前设备用的就是这个）
       ├── Godot_v4.6.2-stable_macos.app     ← macOS
       └── Godot_v4.6.2-stable_linux.x86_64  ← Linux
   ```
3. 路径必须**精确一致**（`engine/Godot/` 下），项目脚本和 `.bat` 启动器都按此路径引用。

> 验证：Windows 下双击 `engine/Godot/Godot_v4.6.2-stable_win64.exe` 能打开 Godot 即可。

## 4. 必做：替换设备相关绝对路径

仓库里有几处**硬编码绝对路径**，当前值是 `d:/AI/GameStudio`，新设备/新工作空间必须改成实际路径。

### 4.1 CodeBuddy Hook 路径（★最关键，不改 hook 会失效）

**文件：** `.codebuddy/settings.json`

当前内容（3 个 hook 全部指向 `d:/AI/GameStudio`）：
```json
{
  "hooks": {
    "SessionStart":     [{ "command": "python d:/AI/GameStudio/.codebuddy/hooks/session-start.py" }],
    "UserPromptSubmit": [{ "command": "python d:/AI/GameStudio/.codebuddy/hooks/user-prompt-route.py" }],
    "PreToolUse":       [{ "command": "python d:/AI/GameStudio/.codebuddy/hooks/pre-tool-bash.py" }]
  }
}
```

把 3 处 `d:/AI/GameStudio` 全部替换为新工作空间根目录绝对路径。例如：
- Windows：`python E:/Work/GameStudio/.codebuddy/hooks/session-start.py`
- macOS：`python /Users/you/GameStudio/.codebuddy/hooks/session-start.py`

### 4.2 Agent Spawn 合约路径

**文件：** `.codebuddy/rules/agent-spawn-contract/RULE.mdc`（及 `MANUAL.md`）
搜索 `d:/AI/GameStudio/projects/<name>/game`，把前缀 `d:/AI/GameStudio` 改为实际路径。

### 4.3 其它含旧路径的文件（不影响运行，可选清理）
